##  Panduan Penggunaan (Usage Tutorial)

### Langkah 1: Memulai Aplikasi
1.  Saat pertama kali dibuka, Anda akan masuk ke **Landing Page**. Tekan **Sign In** jika sudah punya akun, atau **Sign Up** untuk mendaftar.
2.  Setelah masuk, Anda akan berada di **HomePage**. Gunakan **Search** di pojok kanan atas untuk mencari produk spesifik.

### Langkah 2: Menjelajah Produk
1.  Gunakan **Action Chips** di bawah banner untuk memfilter produk (misal: klik 'Groups' untuk melihat merchandise per grup idol).
2.  Klik pada **Gambar Produk** untuk masuk ke halaman detail. Di sini Anda bisa melihat spesifikasi lengkap dan harga promo.

### Langkah 3: Menggunakan Voucher
1.  Di halaman utama, klik banner **"Klaim Voucher Diskon"**.
2.  Tekan tombol **Klaim**. Voucher yang sudah diklaim akan berubah statusnya menjadi **Sudah Diklaim**.
3.  Ingat kode vouchernya (misal: `KSTORELOVE`) untuk digunakan saat checkout.

### Langkah 4: Proses Belanja & Checkout
1.  Klik ikon **Keranjang** di pojok kanan atas untuk melihat daftar belanjaan Anda.
2.  Tekan tombol **Checkout**.
3.  Isi data pengiriman dengan lengkap. **Email dan Alamat tidak boleh kosong**.
4.  Masukkan kode voucher di kolom voucher untuk memotong total harga.
5.  Pilih **Metode Pembayaran**. Jika memilih Bank/E-Wallet, pastikan memilih salah satu provider yang tersedia di dropdown.
6.  Tekan **Pay now**. Jika data valid, muncul notifikasi **"Payment Successful!"**.

### Langkah 5: Cek Riwayat Pesanan
1.  Masuk ke menu **Profile** (ikon orang di pojok kanan atas).
2.  Klik pada daftar **Order History**.
3.  Di sini Anda bisa melihat summary belanjaan, total harga, dan metode pembayaran yang Anda pilih sebelumnya.



##  Teknologi yang Digunakan
*   **Framework**: Flutter (Dart)
*   **State Management**: Provider (untuk Keranjang Belanja)
*   **Styling**: Vanilla Flutter Material Design 3
*   **Iconography**: Material Icons & Cupertino Icons
*   **Data Handling**: Dummy Data Generator (Product Models)


##  Cara Menjalankan Proyek
1.  Clone repositori ini.
2.  Pastikan Flutter SDK sudah terinstal.
3.  Jalankan `flutter pub get` di terminal.
4.  Hubungkan perangkat atau emulator.
5.  Jalankan `flutter run`.
